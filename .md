# 🧪 Practical Code Examples: Transformer 2D vs 3D Matrix

Aao ise ek **Real Question & Options** ke example se samajhte hain:

> **Example Question:** "What is the capital of France?"  
> **Options:** A) London | B) Paris | C) Berlin | D) Madrid | E) Rome  

---

## 1. AutoModelForSequenceClassification (2D Tensor Example)

Yeh model input mein **5 Strings ki Single List** leta hai.

### 💻 Code Example:
```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification
import torch

tokenizer = AutoTokenizer.from_pretrained("microsoft/deberta-v3-small")
model = AutoModelForSequenceClassification.from_pretrained("microsoft/deberta-v3-small", num_labels=5)

# Step 1: 5 Options ke 5 Individual Text Pairs banaye
prompt_pairs = [
    "What is the capital of France? [SEP] London", # Choice A
    "What is the capital of France? [SEP] Paris",  # Choice B
    "What is the capital of France? [SEP] Berlin", # Choice C
    "What is the capital of France? [SEP] Madrid", # Choice D
    "What is the capital of France? [SEP] Rome"    # Choice E
]

# Step 2: Tokenize (Returns 2D Tensor)
inputs = tokenizer(prompt_pairs, return_tensors="pt", padding=True)
print("Input Shape:", inputs["input_ids"].shape) 
# 🖨️ Output: torch.Size([5, 14]) -> [5 Sentences, 14 Tokens]

# Step 3: Pass 2D Tensor directly to Model (NO .unsqueeze(0))
with torch.no_grad():
    outputs = model(**inputs)

logits = outputs.logits
print("Raw Logits Matrix Shape:", logits.shape)
# 🖨️ Output: torch.Size([5, 5]) -> [5 Sentences x 5 Class Logits]
``` 

### 👁️ Visualizing the Raw Output Matrix [5, 5]:
Model ne har sentence par 5-5 scores feke hain:
```
Plaintext
Row 0 (London): [-0.2,  0.5,  0.1, -0.4,  0.3]
Row 1 (Paris) : [ 1.8, -0.1, -0.5,  0.2, -0.3]  <-- Is Row ka 1st score (1.8) highest hai!
Row 2 (Berlin): [-0.5,  0.2,  0.4, -0.1,  0.0]
Row 3 (Madrid): [-0.8,  0.1, -0.3,  0.6, -0.2]
Row 4 (Rome)  : [-0.3,  0.0,  0.2, -0.5,  0.1]
```
❌ Yeh Galti Mat Karna (Un-sliced Softmax):
Agar tum pure [5, 5] matrix par bina dimension choose kiye softmax aur argmax lagaoge, toh PyTorch is matrix ko Flatten kar ke 25 numbers banayega, aur tumhara top_index 0 se 24 ke beech mein aa jayega (jisse id_to_option[20] par Error aayega)!

```python
# ✅ Slicing Fix (1D Array Banao):
# Humein har row ka pehla score (logits[:, 0]) nikalna hai:

Python
# Select 0th column across all 5 rows
choice_logits = logits[:, 0] 
print("Choice Logits Shape:", choice_logits.shape)
# 🖨️ Output: torch.Size([5]) -> [-0.2, 1.8, -0.5, -0.8, -0.3]

probs = torch.softmax(choice_logits, dim=-1)
top_index = torch.argmax(probs).item()

id_to_option = {0: "A", 1: "B", 2: "C", 3: "D", 4: "E"}
print("Predicted Option:", id_to_option[top_index])
# 🖨️ Output: Predicted Option: B  (Paris)
```

# 2. AutoModelForMultipleChoice (3D Tensor Example)
Yeh model input mein 3D Tensor [1, 5, SeqLen] leta hai. 
``python 
from transformers import AutoTokenizer, AutoModelForMultipleChoice
import torch

tokenizer = AutoTokenizer.from_pretrained("microsoft/deberta-v3-small")
model = AutoModelForMultipleChoice.from_pretrained("microsoft/deberta-v3-small")

question = ["What is the capital of France?"] * 5
options = ["London", "Paris", "Berlin", "Madrid", "Rome"]

# Step 1: Tokenize
inputs = tokenizer(question, options, return_tensors="pt", padding=True) # Returns [5, 14]

# Step 2: 3D Tensor Banao using .unsqueeze(0)
input_ids_3d = inputs["input_ids"].unsqueeze(0)             # Shape: [1, 5, 14]
attention_mask_3d = inputs["attention_mask"].unsqueeze(0)   # Shape: [1, 5, 14]

print("3D Input Shape:", input_ids_3d.shape)
# 🖨️ Output: torch.Size([1, 5, 14]) -> [1 Batch, 5 Choices, 14 Tokens]

# Step 3: Pass 3D Tensor to Model
with torch.no_grad():
    outputs = model(input_ids=input_ids_3d, attention_mask=attention_mask_3d)

logits = outputs.logits
print("Logits Shape:", logits.shape)
# 🖨️ Output: torch.Size([1, 5]) -> [1 Question x 5 Direct Choice Scores]
``` 
👁️ Visualizing the Direct Logits Matrix [1, 5]:
Isko slicing ki zaroorat nahi hai, yeh direct 5 options ke scores deta hai:PlaintextLogits: [[ -0.42,  2.85, -0.12, -0.65, -0.31 ]]
           │      │      │      │      │
        Option A Option B Option C Option D Option E
Pythonprobs = torch.softmax(logits, dim=-1).squeeze(0) # Shape: [5]
top_index = torch.argmax(probs).item()

print("Predicted Option:", id_to_option[top_index])
# 🖨️ Output: Predicted Option: B  (Paris)
```
